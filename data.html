Welcome to Data Fundamentals

Data is information collected about people, objects or events. Learning data fundamentals helps you organize information, identify patterns and make evidence-based decisions.

Video requires an internet connection. Use the lessons below if the video is unavailable.

MODULE 01

What Is Data?

Data can be numbers, text, dates, images or measurements.

  • Quantitative data: Numerical measurements, such as marks or age.
  • Qualitative data: Categories or descriptions, such as favorite subject.
  • Structured data: Information organized into rows and columns.
Example: A student's test score of 85 is quantitative data. The student's favorite subject, Computer Science, is categorical data.

MODULE 03

Basic Statistics

Statistics summarize data so that you can understand it more easily.

  • Mean: Add the values and divide by the number of values.
  • Median: The middle value after sorting the values.
  • Mode: The value that appears most often.
  • Range: The largest value minus the smallest value.
Scores: 60, 70, 80
Mean = (60 + 70 + 80) ÷ 3 = 70
Range = 80 − 60 = 20
