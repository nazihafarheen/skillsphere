YOUR FIRST LESSON

Welcome to Front-End Development

Front-end development focuses on the part of a website that users see and interact with. HTML creates structure, CSS controls appearance, and Bootstrap helps you build responsive layouts.

Video requires an internet connection. If it is unavailable, use the written lessons below.

MODULE 01

Introduction to HTML

HTML stands for HyperText Markup Language. It defines the structure of a web page.

Example

<h1>Welcome to my website</h1>
<p>I am learning HTML.</p>
<a href="index.html">Go home</a>

What you should understand

  • Headings use elements such as h1 and h2.
  • Paragraphs use the p element.
  • Links use the a element and its href attribute.
MODULE 02

CSS Fundamentals

CSS stands for Cascading Style Sheets. It controls colors, spacing, typography and layout.

h1 {
  color: #7357ee;
  font-size: 36px;
}

p {
  line-height: 1.8;
}

Keep your styles in a file named style.css and link it from your HTML document.

MODULE 03

Responsive Design

Responsive design makes a website adapt to different screen sizes.

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

Bootstrap's grid system uses containers, rows and columns to arrange content across screens.

MODULE 04

Bootstrap Basics

Bootstrap provides ready-made CSS classes for layouts, buttons, navigation and more.

<div class="container">
  <div class="row">
    <div class="col-md-6">
      Your content
    </div>
  </div>
</div>

Use the Bootstrap CSS CDN in the head of your page to access these styles.
